# Prompted Journal

A morning ritual with a wizard. Name the feeling → two follow-up questions → a journaling
prompt → write → a spell appears → sit with the gong → a crystal ball appears → the cupboard.

## Rules

- No backend, no auth, no database, no AI API, no subscriptions. `localStorage` only.
- Web app on Vercel. Not Electron, not Tauri, not a native app.
- React + TypeScript + Vite, vanilla CSS. **No Tailwind, no shadcn, no component library.**
  The high-fidelity design was a Figma Make export built on those; it was reimplemented here
  rather than adopted, so the dependency list stays empty.
- Two primary viewports: phone portrait, and a narrow desktop window (400–600px).
- Calm by default. No streaks, no stats, no social, no urgency mechanics, no shame-based copy.
- Product decision rule: "Does this make the morning ritual better?" If no, don't build it.

## Visual language

Grid-notebook paper, pencil drawings, gold and violet magic — taken from the design export.

| Token | Value | Use |
| --- | --- | --- |
| `--paper` | `#fdfcf8` | page |
| `--sand` | `#ede9e3` | lower panel on split screens |
| `--ink` | `#1b1624` | text, primary buttons, journal bar |
| `--gold` | `#e8b84b` | Aldric, margin rule, spells |
| `--violet` | `#7c6ff7` | the gong, crystal balls |

- **The grid is CSS**, two hairline gradients at 28px on `body`. Sharp at any zoom and free —
  do not replace it with the paper photographs in `images/`, which are ~6MB each.
- **The drawings are scans on white paper.** They use `mix-blend-mode: multiply` so the page
  drops out and only the pencil remains. On the dark whisper bar that would erase them, so
  there they use `filter: invert(1)` + `mix-blend-mode: screen` instead.
- Source art lives in `images/`; the web-sized copies in `public/` were generated by a
  throwaway script (decode → crop → box-downscale → flatten near-white → posterise → re-encode).
  Near-white is flattened to pure white deliberately: it kills scanner noise, compresses hard,
  and is exactly what `multiply` discards.

## Architecture

```
src/
  components/   Home, EmotionPicker, FollowUp, Journal, RewardReveal, RewardArt,
                GongScreen, Cupboard, Wizard, LaunchHelp
  core/         timer.ts, persistence.ts, useTimer.ts — from the wizard-timer project.
                Treat as a shared library: fix bugs here, don't restyle it.
  data/         emotions.ts (31 emotions in 3 groups), questions.ts (two questions per
                branch), prompts.ts (98 prompts + selector), rewards.ts (spells and orbs)
  hooks/        useSpeechRecognition, useDisplayMode
  utils/        gong.ts (Web Audio), storage.ts (today's session), collection.ts (the shelf)
  App.tsx       owns stage routing, the session, and the collection
```

### Two separate stores, on purpose

- `storage.ts` holds **today's session** — date-scoped, thrown away tomorrow.
- `collection.ts` holds **the collection** — never expires, and is what the cupboard shows.

Losing a half-finished entry overnight is fine. Losing the shelf is not.

### The check-in

Each emotion belongs to a **branch** (`activated`, `low`, `self-critical`, `outward`, `bright`,
`settled`, `neutral`). The branch decides the two follow-up questions, so they change with the
feeling. Adding an emotion means assigning it a branch. Answer ids are globally unique
(`out-person`, `low-weeks`) so a prompt can name one directly.

### Rewards

Journaling earns a **spell** (left shelf), the gong earns a **crystal ball** (right shelf).
`nextReward` prefers something not yet collected, so each session brings a new one, and starts
round again once a set is complete. There is deliberately **no unlock schedule yet** — every
session earns one of each.

### Emoji

Single codepoint, Unicode 11 or earlier. Windows 10's Segoe UI Emoji renders Unicode 13/14 as
empty boxes and splits ZWJ sequences like 😮‍💨 into two glyphs.

## Launching it

Installable PWA (`public/manifest.webmanifest`, `display: standalone`). Installed, it gets its
own window on desktop and full screen on a phone. `LaunchHelp` shows on the home screen only,
and hides once installed, once already in the popped-out window, or once dismissed. Desktop vs
mobile copy is chosen by `(hover: hover) and (pointer: fine)`, **not** width.

## Durations

`JOURNAL_MINUTES` and `MEDITATION_MINUTES` in `src/App.tsx`. Change there, nowhere else.
